On a Mac? macOS warns the first time you open a downloaded copy, because Tensile is not yet notarized by Apple. See Installing for the two-minute fix, or use the Terminal command there to skip the warning entirely.

Which Mac do I have? Open the Apple menu, then About This Mac. If it says Chip: Apple M…, pick Apple chip. If it says Processor: … Intel, pick Intel chip.

Installing

Easiest: install from Terminal. Open the Terminal app, paste this and press Return. It picks the right version for your Mac and opens without any warning:

curl -fsSL https://raw.githubusercontent.com/ShubhamSingh047/tensile/main/install.sh | sh

If you downloaded the .zip: Tensile is not yet notarized by Apple, so the first time you open it macOS says it "could not verify Tensile is free of malware". That is expected. To open it:

  1. Open the .zip and drag Tensile into Applications.
  2. Double-click Tensile. When the warning appears, click Done (not Move to Bin).
  3. Open System Settings, then Privacy & Security. Scroll down to the message "Tensile was blocked" and click Open Anyway.
  4. Enter your Mac password, then click Open Anyway once more. After this, Tensile opens normally.

Or skip steps 2 to 4 by running this once in Terminal after step 1:

xattr -dr com.apple.quarantine /Applications/Tensile.app
  1. Run Tensile-windows-x64-setup.exe.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  3. Follow the installer. Tensile appears in the Start menu.

The warning appears because the installer is not code-signed yet.

  1. Make the file runnable, then start it:
chmod +x Tensile-linux-x64.AppImage && ./Tensile-linux-x64.AppImage

Or install the app and the tensile command with:

curl -fsSL https://raw.githubusercontent.com/ShubhamSingh047/tensile/main/install.sh | sh

The tensile command runs the same load tests from a terminal or CI. On macOS and Linux:

curl -fsSL https://raw.githubusercontent.com/ShubhamSingh047/tensile/main/install.sh | sh -s -- --cli

On Windows, download tensile-windows-x64.zip and put tensile.exe on your PATH. Every file is listed with its checksum on the release page.
